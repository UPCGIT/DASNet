DASNet: Direction-Augmented and Sparsity-Adaptive Network for Hyperspectral Lithology Classification

If you use the code, please cite the paper:
H. Zheng et al., "DASNet: Direction-Augmented and Sparsity-Adaptive Network for Hyperspectral Lithology Classification," in IEEE Journal of Selected Topics in Applied Earth Observations and Remote Sensing, vol. 19, pp. 30795-30812, 2026, doi: 10.1109/JSTARS.2026.3719705.

The code in this toolbox implements the "DASNet: Direction-Augmented and Sparsity-Adaptive Network for Hyperspectral Lithology Classification".

The labels of our dataset were produced based on the reference [W. Xie, “Lithology identification and automatic classification based on GF-1 and Landsat 8 data: A case study of Changji area, Eastern Tianshan, Xinjiang,” M.S. thesis, Chang’an University, Xi’an, China, 2022. doi:10.26976/d.cnki.gchau.2022.001547.], geological maps and previous literature. The dataset is a preprocessed hyperspectral dataset with a spatial resolution of 10 m and 283 bands, generated by fusing GF-5 and Sentinel-2A data via the GSA fusion method. This dataset is available for access. If you use our dataset, please cite our paper “DASNet: Direction-Augmented and Sparsity-Adaptive Network for Hyperspectral Lithology Classification”.
